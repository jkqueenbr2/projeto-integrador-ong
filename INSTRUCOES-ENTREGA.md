# Instruções de publicação e entrega

1. Confirme que o projeto escolhido é realmente o Projeto Integrador do grupo; substitua o exemplo se não for.
2. Preencha nomes e papéis reais no README e em docs/time-agil.md; valide a matriz de stakeholders da Aula 11.
3. Publique README.md, .github/ISSUE_TEMPLATE/funcionalidade.md, .github/ISSUE_TEMPLATE/bug.md, .github/pull_request_template.md e docs/time-agil.md na branch padrão do repositório.
4. Crie pelo menos oito issues reais usando o template de funcionalidade, copiando os itens de docs/backlog-para-criar-no-github.md. Verifique que os títulos dos campos permanecem.
5. No GitHub Projects vinculado ao repositório, configure TO-DO, DOING e DONE. Adicione as oito issues e declare o limite de WIP = 2 (ou ajuste ao tamanho real do grupo). O quadro não é criado pelo ZIP.
6. Realize pelo menos três mudanças reais em branches, abra três PRs seguindo o template e vincule cada PR a uma issue correta com Closes #N. Os exemplos em docs/modelos-de-3-prs.md não são PRs criados.
7. Garanta commits reais de pelo menos dois integrantes diferentes e contribuição rastreável de cada membro.
8. Confira visibilidade pública do repositório e do quadro ou conceda acesso ao usuário gomescarlosrjr em ambos.
9. Cada integrante envia no AVA, até 25/10/2026 23h59, nesta ordem:
