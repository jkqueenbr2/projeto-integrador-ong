# Amor de Patas — Projeto Integrador

## Objetivo
Desenvolver uma plataforma para apoiar uma ONG de proteção animal na divulgação de animais disponíveis para adoção e na organização das solicitações de interessados. O público-alvo são voluntários, administradores da ONG e potenciais adotantes.

## Escopo
**Nesta fase:** listagem de animais, ficha individual, cadastro de animais por administradores, formulário de interesse em adoção, acompanhamento do status das solicitações e autenticação de administradores.

**Fora do escopo nesta fase:** pagamentos, integração com clínicas veterinárias, aplicativo móvel nativo e avaliação automática de candidatos.
